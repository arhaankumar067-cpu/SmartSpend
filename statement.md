# SmartSpend – Project Statement

## Problem Statement

Students often find it difficult to keep track of their daily expenses and maintain a monthly budget. Small expenses related to food, transportation, education, entertainment and shopping can accumulate without proper monitoring.

SmartSpend provides a simple Java-based system for recording, organizing and analyzing expenses while monitoring a monthly budget.

## Scope

The project focuses on expense tracking and personal budget management for college students.

The system supports expense management, budget management, searching, sorting, reporting and persistent file storage.

## Target Users

The primary target users are college students who want to monitor their daily spending and manage their monthly budget.

## High-Level Features

- Add and view expenses
- Delete expenses
- Search expenses by category
- Search expenses by date
- Sort expenses by amount
- Set monthly budget
- Check budget status
- Generate spending reports
- Category-wise analysis
- Persistent data storage
- Input validation and error handling

## Technologies

The project is implemented using Java and demonstrates:

- Object-Oriented Programming
- ArrayList
- HashMap
- Enum
- File Handling
- Exception Handling
- LocalDate
